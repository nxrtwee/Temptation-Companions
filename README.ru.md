# Temptation Companions

Взрослые NPC-компаньонки для **Minecraft 26.2** (Fabric). Позовите компаньонку, договоритесь о сцене
в её меню, заплатите — и мод сам отыграет сцену с анимациями и постановочной камерой.

> **Только 18+.** Мод добавляет откровенный сексуальный контент. Не устанавливайте его, если вы
> несовершеннолетний, и не ставьте на сервер, где играют дети.

Статус: **альфа.** Играется от начала до конца, но шероховатости есть — расстановка сцен, кадрирование
камеры и пропорции ещё настраиваются, и включена пока не вся оригинальная ростер-подборка.

## Возможности

- **Четыре компаньонки** — Jenny, Ellie, Bia и Luna, у каждой своя модель, озвучка и набор сцен.
- **Анимированные сцены**: подход, анимация оплаты, вступление, активная фаза с темпом и финал; всё
  ведётся со стороны сервера, поэтому в мультиплеере сцены не расходятся.
- **Постановочная камера** — своё кадрирование для каждой фазы каждой сцены, с затемнением на склейках.
- **Меню взаимодействия** в духе оригинала: кнопки сцен по категориям, с ценой рядом с каждой, плюс
  общие команды по левому краю.
- **Команды компаньонке** — идти за мной, стоять, идти домой, задать новый дом, панель снаряжения;
  броня и предметы в руках отображаются на модели.
- **Свободная камера**, которой можно летать во время сцены.
- **Панель подгонки** прямо в игре: дистанция камеры, расстановка сцены и пропорции тела, с сохранением
  в конфиг.
- **Английская и русская** локализация.

## Требования

| | |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | 0.19.3 или новее |
| Fabric API | любая сборка под 26.2 (разработка идёт на 0.155.2+26.2) |
| GeckoLib | 5.5.3 под 26.2 |
| Java | 25 |

## Установка

1. Установите Fabric Loader для 26.2.
2. Положите **Fabric API**, **GeckoLib** и jar Temptation Companions в `.minecraft/mods`.
3. Запустите игру.

## С чего начать

```
/sexmod spawn jenny
```

Сами компаньонки не спавнятся — используйте команду (`jenny`, `ellie`, `bia`, `luna`). Нажмите на
компаньонку правой кнопкой, чтобы открыть меню, выберите категорию, затем сцену; цена должна быть у
вас в инвентаре.

У каждой компаньонки свой набор сцен; в меню видно, что она предлагает и сколько это стоит — от одного
золотого слитка до трёх изумрудов, оплата золотом, алмазами, изумрудами или жемчугом Края. Часть сцен
происходит на кровати, для них нужна кровать поблизости — компаньонка сама дойдёт до неё и позовёт вас.

`/sexmod scene <название>` запускает сцену с ближайшей компаньонкой в радиусе 8 блоков — удобно для
проверки.

## Управление

Во время сцены:

| Клавиша | |
|---|---|
| **Shift** | темп — нажатием или удержанием |
| **Space** | финал, когда шкала заполнена; иначе завершает сцену |
| **X** | завершить сцену |
| **G** | свободная камера |
| **N** | панель подгонки |

При включённой свободной камере `[` `]` меняют скорость перемещения, а `;` `'` — скорость по высоте.
Клавиши на нумпаде подстраивают затемнение на склейках. Всё переназначается в Настройки → Управление →
Temptation Companions.

## Конфигурация

Подгонка, сделанная в игре, пишется в `.minecraft/config/`:

- `sexmod-camera.json` — кадрирование камеры по компаньонке, сцене и фазе
- `sexmod-jenny-scene-layout.properties` — расстановка пары для каждой сцены
- `sexmod-jenny-scene-body.properties` — пропорции тела по сценам

В файлах лежит только то, что вы изменили. Удалите файл, чтобы вернуться к значениям из мода.

## Сборка из исходников

```bash
git clone https://github.com/nxrtwee/Temptation-Companions
cd Temptation-Companions
./gradlew build
```

Jar появится в `build/libs/`.

Двух вещей в репозитории **нет**, их нужно положить локально:

- **GeckoLib** — релиза в Maven под 26.2 нет, поэтому положите `geckolib-fabric-26.2-5.5.3.jar` в
  `libs/`.
- **Ассеты персонажей** — модели, анимации, текстуры и звуки здесь не распространяются. Свежий клон
  компилируется и запускается, но компаньонки останутся невидимыми и беззвучными, пока в
  `src/main/resources/assets/sexmod/` не появится дерево ассетов (`geckolib/`, `textures/`, `sounds/`).
